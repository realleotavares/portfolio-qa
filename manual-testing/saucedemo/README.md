# SauceDemo - Testes Manuais de E-commerce

### Resumo
Neste módulo, eu modelo testes manuais utilizando o [SauceDemo](https://www.saucedemo.com/), um e-commerce sandbox padrão da indústria. Meu objetivo aqui é demonstrar a base analítica que antecede a automação que já desenvolvi nas pastas `e2e-playwright` e `e2e-robot`.

### Escopo de Testes
1. **Casos de Teste Tradicionais:** Criei casos de teste passo-a-passo (`CT01_fluxo_de_checkout.md`) focados no fluxo crítico de compras (Adicionar ao carrinho -> Checkout -> Sucesso).
2. **BDD (Behavior-Driven Development):** Desenvolvi cenários em Gherkin (`.feature`) para o fluxo de Autenticação, cobrindo cenários positivos e matrizes de dados negativos (Esquema do Cenário) para tentativas de intrusão.

# SauceDemo - Pruebas Manuales de E-commerce

### Resumen
En este módulo, modelo pruebas manuales utilizando [SauceDemo](https://www.saucedemo.com/), una plataforma de e-commerce sandbox estándar de la industria. Mi objetivo aquí es demostrar la base analítica que precede a la automatización que ya he desarrollado en las carpetas `e2e-playwright` y `e2e-robot`.

### Alcance de las Pruebas
1. **Casos de Prueba Tradicionales:** Creé casos de prueba paso a paso (`CT01_fluxo_de_checkout.md`) enfocados en el flujo crítico de compras (Añadir al carrito -> Checkout -> Éxito).
2. **BDD (Behavior-Driven Development):** Desarrollé escenarios en Gherkin (`.feature`) para el flujo de Autenticación, cubriendo escenarios positivos y matrices de datos negativos (Esquema del Escenario) para intentos de intrusión.
