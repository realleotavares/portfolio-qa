# Automation In Testing (Restful-Booker) - Testes Manuais

### Resumo
Neste módulo, utilizo a plataforma [Automation In Testing](https://automationintesting.online/) (também conhecida como Restful-Booker Platform) para demonstrar técnicas de testes manuais. Esta aplicação é famosa na comunidade de QA por possuir "bugs intencionais", o que a torna o ambiente perfeito para treinar *Bug Advocacy* e Testes Exploratórios.

### Escopo de Testes
1. **Casos de Teste Tradicionais:** Criei o caso de teste `CT01_formulario_contato_pt.md` para explorar limites e validações de formulário.
2. **BDD (Behavior-Driven Development):** Desenvolvi cenários em Gherkin (`.feature`) focados na lógica de calendário e regras de negócio de reservas.

# Automation In Testing (Restful-Booker) - Pruebas Manuales

### Resumen
En este módulo, utilizo la plataforma [Automation In Testing](https://automationintesting.online/) (también conocida como Restful-Booker Platform) para demostrar técnicas de pruebas manuales. Esta aplicación es famosa en la comunidad de QA por tener "bugs intencionales", lo que la convierte en el entorno perfecto para entrenar *Defensa de Bugs* (Bug Advocacy) y Pruebas Exploratorias.

### Alcance de las Pruebas
1. **Casos de Prueba Tradicionales:** Creé el caso de prueba `CP01_formulario_contacto_es.md` para explorar límites y validaciones de formularios.
2. **BDD (Behavior-Driven Development):** Desarrollé escenarios en Gherkin (`.feature`) enfocados en la lógica del calendario y reglas de negocio de reservaciones.
